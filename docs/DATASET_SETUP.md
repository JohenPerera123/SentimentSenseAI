# Dataset Setup Instructions

## IMDb Movie Reviews Dataset

- **Purpose**: Used as the primary dataset for supervised sentiment classification (positive vs negative).
- **Expected Filename**: `IMDB Dataset.csv`
- **Expected Columns**: `review`, `sentiment`
- **Location**: Place the downloaded file in `data/raw/imdb/IMDB Dataset.csv`
- **Usage**: The project uses this dataset directly for training and evaluating models. The raw data is never modified. Processed splits are saved into `data/processed/imdb/`.

## Sentiment140 Twitter Dataset

- **Purpose**: Used for testing cross-domain generalization and social media sentiment classification.
- **Expected Filename**: `twitter_dataset.csv` (or `training.1600000.processed.noemoticon.csv`)
- **Expected Raw Structure**: CSV without headers. Contains fields: target, id, date, flag, user, text.
- **Location**: Place the downloaded file in `data/raw/twitter/twitter_dataset.csv`
- **Usage**: The project parses this dataset, standardizes the labels (positive/negative), and samples 50,000 tweets (to maintain class balance). The processed sample and splits are saved into `data/processed/twitter/`.

**Important**: Raw data in `data/raw/` is never modified. Processed data is automatically generated by running `python scripts/prepare_datasets.py`.
